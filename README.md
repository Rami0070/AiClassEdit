# 🌿 스마트 학급편성 시스템 (특이사항 컬러 & 분리요청 지원)

학교 현장 맞춤형 초정밀 학급 배정 시스템입니다.  
7대 제약 조건, **비고란 특이사항별 고유 색상 표시**, **분리요청(사람이름) 무조건 다른 반 배정**, **모든 엑셀 시트 자동 취합**, **드래그 앤 드롭**을 완벽하게 지원합니다.

## 🛡️ 2. 분리요청(사람이름) 무조건 다른 반 배정 규칙 (Hard Constraint)

- **표기법 지원:**
  - `분리요청 (김철수)`, `분리요청(김철수)`, `분리: 김철수`, `분리 김철수`, `분리-김철수`
  - 복합 기재 지원: `생활지도, 분리요청(이민준)`
- **알고리즘 작동:**
  - 양방향 하드 제약(Hard Constraint)으로 등록되어, 두 학생이 **동일 반에 배정될 경우 100만 점의 강력한 페널티**를 부과합니다.
  - 최적화 엔진이 분리 요청 대상자들을 자동으로 감지하여 **무조건 서로 다른 진급반**에 배정합니다.
  - 결과 대시보드 상단에 **`분리 요청 준수: 완벽 분리 (0건 위반)`** 통계 카드가 표시됩니다.
  - 수동으로 반을 변경할 때도 분리 요청 위반이 발생하면 즉각 붉은색 경고 배지와 알림이 뜹니다.

## 📋 3. 표준 엑셀 입출력 서식

### 업로드 양식 (9개 컬럼 - 진급반 컬럼 제외)
```
반 | 번호 | 이름 | 성별 | 국어 | 수학 | 합계 | 석차 | 비고
```
- **시트 이름 = 기존 반 이름:** 각 시트 이름(1반, 2반...)이 학생들의 기존 반으로 자동 인식 및 취합됩니다.
- 진급반은 배정 연산 후 **가반, 나반, 다반, 라반...** 순으로 자동 편성됩니다.

### 배정 결과 양식 (8개 컬럼)
```
반 | 번호 | 이름 | 성별 | 석차 | 진급반 | 번호 | 비고
```
- **번호 (새 번호):** 진급반 내에서 **남녀 구분 없이 전체 이름순(가나다순)으로 1번부터 N번까지 부여** (기본 표준 모드)
  - 필요 시 설정 화면에서 [남 1번~ / 여 21번~], [여 1번~ / 남 21번~], [남 1번~ / 여 1번~]으로 즉시 전환 가능.

## 🚀 빠른 실행 방법

### 방법 1 (가장 추천: 단독 exe 실행)
- **`학급편성.exe`** (또는 **`스마트학급편성.exe`**) 파일을 더블클릭합니다.
- **기타 부가 파일(HTML, BAT 등) 없이 exe 단독으로 바탕화면이나 USB에 복사하여 어디서든 바로 실행**할 수 있습니다.
- 주소창이나 탭이 없는 깔끔한 독립 데스크톱 전용 앱 창 모드로 실행됩니다.

### 방법 2 (웹 브라우저 직접 실행)
- **`index.html`** 파일을 더블클릭하거나, **`실행하기.bat`** (또는 영문 시스템용 **`run.bat`**) 파일을 더블클릭합니다.
- 기본 웹 브라우저(Edge, Chrome 등)에서 시스템 대시보드가 열립니다.
